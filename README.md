# [Group 2] Fetch-Decode-Execute Exhibit

An interactive educational web application that teaches the **Fetch–Decode–Execute (FDE) Cycle** through guided lessons, visual simulations, and interactive activities for Computer Architecture students.

🌐 **Live Demo:** https://csarch-2-g4-s40.netlify.app/

---

## Overview

FDE exhibit is an interactive exhibit developed to make the Fetch–Decode–Execute cycle easier to understand. Instead of relying only on static lecture slides, the application allows users to learn through explanations, visualizations, and hands-on activities while receiving immediate feedback.

---

## Features

### Phase 1 – Intuition
- Chef and kitchen analogy introduction
- Interactive intuition activity
- Context-specific feedback for incorrect answers
- Keyboard accessibility support

### Phase 2 – Theory
- Guided explanation of the FDE cycle
- Interactive review questions
- Per-question feedback
- Consistent monospace styling

### Phase 3 – Interactive CPU Diagram
- Interactive CPU architecture diagram
- Component information during Fetch, Decode, and Execute
- Bus labels:
  - Address Bus
  - Data Bus
  - Control Bus
  - System Bus

### Phase 4 – Challenge
- Bus connection activity
- Context-aware hints for incorrect answers

### References
- Built-in citations panel
- Mobile-friendly layout
- Direct navigation from the navigation bar
